# Request for Proposal — CAATH GST API Partnership

## Ready-to-send email

**Subject:** ASP partnership enquiry for GST API integration — CAATH

Dear GSP Partnership Team,

We are developing CAATH, a cloud-based practice management and GST compliance platform for CA, CMA, CS, Income Tax Practitioner and Sales Tax Practitioner practices in India. We are evaluating GSTN-empanelled GSP partners so CAATH can operate as an ASP and provide consent-based GST services to its customers.

Our planned scope includes:

- taxpayer authentication and consent;
- GSTR-1, GSTR-3B, GSTR-2A and GSTR-2B retrieval;
- return preparation, validation, filing and ARN/status retrieval;
- notice and order retrieval where supported;
- challan creation, status and payment-reference retrieval;
- multi-GSTIN operations, sandbox testing and production onboarding;
- e-invoice/e-way bill APIs as a later phase.

Please share:

1. Your current GSTN empanelment details and ASP/reseller onboarding process.
2. Sandbox access procedure, API documentation and sample collections.
3. Supported APIs and any unavailable/limited operations.
4. Pricing per GSTIN/API/filing, minimum commitment, setup fee and taxes.
5. Rate limits, uptime SLA, support escalation and onboarding timeline.
6. Authentication, OTP, consent, IP allow-list and production-certification requirements.
7. Data residency, encryption, retention, incident-notification and audit provisions.
8. Agreement, DPA, confidentiality and exit/data-portability terms.

CAATH already has a provider-neutral adapter, tenant-isolated consent records, sandbox/production separation, idempotent job tracking and a production kill switch. We can begin sandbox integration after technical and commercial evaluation.
